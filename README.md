# Piyush Kumar — 3D Cybernetic Portfolio Master Package

This master folder contains the complete, production-ready portfolio ecosystem for Piyush Kumar.

## Folder Structure
- `01_Website_Source_Code/`: Complete HTML, CSS, JavaScript, and 3D WebGL assets.
- `02_Documentation_And_Credentials/`: Full biography, resume data, and academic credentials.
- `03_Data_And_Specifications/`: Structured JSON/JS data and system specifications.

## How to Run Locally
1. Double-click `01_Website_Source_Code/index.html` to open in any web browser.
2. Or run: `python -m http.server 8080 --directory 01_Website_Source_Code`
